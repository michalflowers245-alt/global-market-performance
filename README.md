# 全球市场涨幅对比

本机交互图表用于比较美股指数及 ETF、A 股宽基指数和比特币。页面支持查看原始价位、区间涨幅、归一化对比、比特币回撤、最近报价和 CSV 导出。

## 启动

需要 Python 3.10 或更新版本，以及支持 `DecompressionStream` 的现代浏览器。项目使用 Python 标准库。

首次运行时联网拉取各数据源。在项目目录运行下面的命令，然后打开终端显示的本机地址，默认是 `http://127.0.0.1:8769/`。

```sh
python3 market_server.py --build --serve
```

已有本地快照时可直接运行 `python3 market_server.py --serve`。macOS 可以双击 `打开实时对比.command` 打开本机页面。

## 数据与口径

首次更新在本机生成历史日线、累计涨幅汇总和最近行情快照。历史序列依赖 Yahoo Finance、东方财富、Coin Metrics 和 Wilshire 历史档案。比特币最近成交数据来自 Coinbase Exchange。页面列出采集来源和时间，公开行情可能延迟，市场休市时展示最近报价。

跨市场对比使用各标的在所选日期当日或之后的首个共同观测日作为基准。指数采用价格指数，ETF 采用拆分调整收盘价，累计涨幅不含现金分红、换汇和通胀调整。比特币的早期估算价在图中独立标记。

历史 CSV 与行情快照由本机程序写入，仓库保留代码和使用说明。上游访问失败时，可稍后重试首次拉取。
